## 二、考前核心题型验收清单

### FIB-RW（高优先级）

- [ ] **熟题：**独立正确率目标 ≥90%，多数熟悉搭配约5–10秒内辨认（不含阅读整段时间）。
- [ ] **陌生题：**争取约75%–80%正确，允许充分阅读与排除；速度不作为唯一指标。
- [ ] 能说明答案依据：词性 → 语法 → 固定搭配 → 上下文逻辑。
- [ ] 记住答案但不理解的题仍标🟠；遇到有合理互换的选项，不强记“唯一语法规则”。
- [ ] 优先复习现有唯一总表中的高频搭配，不人为新设“必须背100组”任务。

### FIB-R

- [ ] 熟题独立正确率目标 ≥90%；陌生题争取约75%–80%。
- [ ] 能辨析近义词搭配，例如 dramatic/costly、reduce/decrease、benefit/advantage。
- [ ] 做对但拿不准也保留🟠并记录原因；不把平台固定答案等同于绝对的语言规律。

### FIB-L

- [ ] 熟题正确率目标 ≥90%；陌生题争取约80%。
- [ ] 首次播放抓住关键词、语法词尾与拼写；订正后正确不可冒充首次正确。

### RS

- [ ] 高频熟句第一次听完可稳定复述主要内容，争取保留约80%–90%关键词。
- [ ] 长句能按意群记忆；遗漏少量词仍继续复述，不因为一个词停下。
- [ ] 先听一次→先复述→看原文→复习；不将二次练习表现记为首次表现。
- [ ] 不要求“100句逐字零误”才算达标；重点是陌生句迁移。

### WFD

- [ ] 高频熟句首听大多全对（可用≥90%全对作为训练目标）；陌生句尽量只漏0–1词。
- [ ] 核查冠词、介词、复数、时态与拼写；一词遗漏仍按既定🟠标记。
- [ ] 按原规则：漏1–2词🟠；多处遗漏或结构不稳🔴；首听一次完全正确🟢。
- [ ] 第二遍订正不替代第一次成绩；不要求“50句全部零错误”才能应考。

### RA

- [ ] 陌生段落也能平稳朗读、发音清楚、意群停顿自然。
- [ ] 遇到难词不频繁重读全句；不追求机械“零停顿”。
- [ ] 记录真实朗读表现，第三方不同评分系统不互相当作官方成绩。

### DI

- [ ] 熟练使用现有 graph / picture / 流程图等既定模板，不新增背诵体系。
- [ ] 能描述柱状图、折线图、饼图、散点图、流程图和普通照片。
- [ ] 抓住标题、类别、最大最小值或主要元素；图中没有数字则不编数字。
- [ ] 陌生题能流利开口并在限时内结束；普通图片称 picture。

### WE / SWT / SST / RTS

- [ ] WE：沿用既定五段式模板，约110–120词，覆盖全部要点，限时完成并检查拼写、语法；不替换模板。
- [ ] SWT：沿用现有关键句＋连接词＋overall策略，按正式题目字数限制与语法要求检查。
- [ ] SST：沿用 The talk was about... / Firstly... / Later... 三句模板，20–30词，保留关键要点，尽量用原文词组。
- [ ] RTS：沿用既定通用模板及已标注的替换段；明确场景要求、说话对象和礼貌收尾。

### RO / ASQ / 其他

- [ ] RO：能利用代词指代、逻辑衔接、主题句排序，不只记住题库顺序。
- [ ] ASQ：高频题能短而准确回答；其他低权重题型遵循42天计划的已有安排。

## 三、熟题、陌生题及颜色规则

| 状态 | 判定标准 | 记录方式 |
| --- | --- | --- |
| 🟢 稳定掌握 | 首次独立正确；能解释原因或流畅作答 | 保留已完成状态 |
| 🟠 基本掌握 | 正确但靠记忆/猜测、仍有犹豫；WFD漏1–2词 | 记录不确定点，按既定轮次复习 |
| 🔴 重点复习 | 错误多或反复遗忘、无法解释关键点 | 按既定优先级复习 |

**特别注意：**熟题准确率 ≠ 陌生题迁移能力；二刷三刷的记忆正确率 ≠ 首次作答正确率。成绩缺失时留空，不推断完成情况。
