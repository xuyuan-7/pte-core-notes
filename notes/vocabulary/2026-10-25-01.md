## ⭐ 易错辨析

| 英文 | 中文／用法 |
| --- | --- |
| last night / the previous night | last night＝说话当天的昨晚；the previous night＝故事／前文某一天的前一晚。 |
| the previous night / the last night | 前一天晚上／某段时期的最后一晚；on the last night 本身是正确结构，但不是“昨晚”的意思。 |
| able / incapable / capable | able to do；incapable of doing；capable of doing。 |
| make it possible / make sth. available | make it possible for sb. to do sth.；make resources available to students。 |
| available to sb. / for sth. / to do sth. | 分别表达可供某人使用、可用于某事、某人有空做某事。 |
| difficult / unable | It is difficult for sb. to do；sb. is unable to do。 |

### 固定搭配

| 英文 | 中文 |
| --- | --- |
| an enormous increase in | ……的大幅增长 |
| major purchases | 大额购买 |
| with the advent of | 随着……出现 |
| distribute sth. to sb. | 向某人分发某物 |
| easily distributed | 容易分发的 |
| credit card usage | 信用卡使用量 |
| an increase in + 名词 | ……方面的增长 |

### 易混辨析

- enormous increase：强调增长幅度很大；major purchases：大额购买。major increase 也正确。
- easily distributed 强调便于分发；easily available 强调容易获得。两种表达都符合语法，但本题答案为 distributed。
