## 语法辨析（5）

| 英文 | 中文／用法 |
| --- | --- |
| which / that（限制性定语从句） | 指物且没有分隔性逗号时，通常均可使用。The book which / that I bought is interesting. |
| , which ...（非限制性定语从句） | 对前面的名词或整件事补充说明；不能用 that 替换。The program, which is new, helps employees. |
| , which makes ... | which 可指前面整件事，后接单数谓语 makes。Costs are rising, which makes it necessary to save money. |
| who / which / that | who 通常指人；which 指物或前面整个情况；that 可用于许多限制性定语从句，但不能引导非限制性定语从句。 |
| there is / it is | there is + 名词：存在……；it is + 形容词：某事是……的。There is uncertainty. / It is uncertain. |

**FIB-RW #28 错题提醒：** addresses（不是 writes）；which（不是 that）；there（不是 it）。demanding、fits 答对。

| 英文／结构 | 中文／用法 |
| --- | --- |
| -tion / -sion | 常见名词后缀：information 信息；decision 决定 |
| -ment | 常见名词后缀：development 发展 |
| -ness | 常见名词后缀：happiness 幸福 |
| -ity / -ty | 常见名词后缀：possibility 可能性；uncertainty 不确定性 |
| -ance / -ence | 常见名词后缀：importance 重要性；difference 差异 |
| -able / -ible | 常见形容词后缀：available 可用的；possible 可能的 |
| -ful / -less | 常见形容词后缀：useful 有用的；careless 粗心的 |
| -ous / -ive | 常见形容词后缀：dangerous 危险的；effective 有效的 |
| uncertainty / uncertain | 名词：不确定性；形容词：不确定的 |
| difficulty / difficult | 名词：困难；形容词：困难的 |
| possibility / possible | 名词：可能性；形容词：可能的 |
| there is + 名词 | 表示存在：There is uncertainty about the result. |
| it is + 形容词 | 描述情况：It is uncertain whether the plan will work. |
| It remains unclear whether ... | ……是否……仍不清楚 |
| 判断顺序 | 先看句意，再看词性和搭配；后缀只是辅助线索，不是绝对规则 |

## 2026-10-23｜昨日阅读错题复盘：近义词与语法辨析

> 对10月22日已记录内容作集中对照复习，补全 obtain / acquire 等未收录词。以下按英文—中文对照整理。

### achieve / pursue / obtain / acquire

| 英文／搭配 | 中文／辨析与例句 |
| --- | --- |
| achieve | 实现、取得（目标或成果）；achieve a goal / achieve success。例：She achieved her goal. |
| pursue | 追求、从事（强调过程）；pursue higher education / pursue a career。例：He decided to pursue higher education. |
| obtain | 获得、取得（证书、许可等）；obtain a degree / obtain permission。例：She obtained a degree. |
| acquire | 获得、习得（知识、技能等）；acquire knowledge / acquire skills。例：Students acquire new skills. |
| pursue higher education ≠ obtain a degree | 前者强调接受高等教育的过程；后者强调最终取得学位。 |

### raise / arise / occur / emerge

| 英文／搭配 | 中文／辨析与例句 |
| --- | --- |
| raise (raised / raised) | 及物动词：引起、提出；raise questions / raise concerns。例：The discovery raised new questions. |
| arise (arose / arisen) | 不及物动词：出现、产生；problems arise / difficulties arose。例：Several problems arose. |
| occur (occurred / occurred) | 不及物动词：发生；an accident occurs；occur to sb. 表示某人想到。例：It occurred to me that I was wrong. |
| emerge (emerged / emerged) | 不及物动词：出现、显现；new evidence emerges / emerge from sth.。例：New evidence emerged. |
| raise vs arise | Something raises questions（某事引发问题）；Questions arise（问题出现）。raise 后可直接接宾语；arise 不可直接接宾语。 |
| occur to sb. | 某个想法浮现在某人脑海：It occurred to me that...；不能说 difficulties occurred to during construction。 |

### survive / preserve / maintain / retain

| 英文／搭配 | 中文／辨析与例句 |
| --- | --- |
| survive | 幸存、留存下来（强调结果）；The manuscript survived. |
| preserve | 主动保存、保护、防止损坏；preserve ancient manuscripts / preserve historical sites。 |
| maintain | 维护、保持（状态、设备、标准）；maintain equipment / maintain standards。 |
| retain | 保留、继续拥有；retain information / retain control。 |
| preserve vs survive | Historians preserved the manuscripts（历史学家保护手稿）；The manuscripts survived（手稿留存下来）。 |

### transport / transmit

| --- | --- |
| transport | 运送具体的人或物；transport goods / transport patients。 |
| transmit | 传输信号、信息；传播疾病；transmit information / signals / diseases。 |

### meet / achieve

| 英文／搭配 | 中文／辨析与例句 |
| --- | --- |
| meet the needs of / meet requirements | 满足……的需求／符合要求；meet demand 也表示满足需求。 |
| achieve a goal / achieve success | 实现目标／取得成功；不能用 achieve the needs 替代 meet the needs。 |

### Although / Despite / Since / Due to

| 英文／搭配 | 中文／辨析与例句 |
| --- | --- |
| Although + 完整从句 | 尽管；Although it was raining, we went out. |
| Despite + 名词／动名词 | 尽管；Despite the rain, we went out. |
| Since / Because + 完整从句 | 因为；Since there are many options, students can choose. |
| Due to / Because of + 名词短语 | 由于；Due to the rain, the event was cancelled. |
| 先判断逻辑，再判断结构 | 让步：although / despite；原因：since / due to。完整从句通常有主语和谓语；名词短语没有独立谓语。 |
