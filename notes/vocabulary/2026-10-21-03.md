### FIB-RW #24｜Information Revolution｜2026-10-21

**本次成绩：2/5。** 错误：challenges → options；insinuating → driving；bulk → wealth。正确：release、affordable。

| 英文 | 中文 |
| --- | --- |
| Information Revolution | 信息革命 |
| technological changes | 技术变革 |
| bring new options to | 给……带来新的选择 |
| become commonplace | 变得普遍 |
| the driving force behind | ……背后的推动力 |
| a wealth of information | 大量的信息 |
| conventional phone lines | 传统电话线路 |
| a vast domain of information | 庞大的信息领域 |
| upon its release | 在它发布时 |
| revolutionize personal computing | 彻底改变个人计算领域 |
| affordable | 价格负担得起的 |
| price tag | 标价；价格 |
| insinuating | 暗示的；影射的 |
| bulk / the bulk of | 大量；……的大部分 |

**辨析：** driving force＝推动力；a wealth of information＝丰富的信息；the bulk of＝……的大部分。
