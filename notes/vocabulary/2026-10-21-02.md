**原始资料：** PTE Core｜错题原文＋单词搭配翻转复习（统一入口）

| **英文** | **中文** |
| --- | --- |
| complex engineering | 复杂的工程设计；complex＝复杂的。 |
| the organization of biological systems | 生物系统的组织结构；organization 也表示组织方式，不只是机构。 |
| be useful for | 对……有用；useful for survival＝有助于生存。 |
| prevail / prevail at last | 占上风、盛行／终于占上风；good sense prevails＝理智占上风。 |
| present / prevent / preclude | present＝呈现、提出；prevent＝阻止；preclude＝排除、使不可能。 |
| There is concern that... | 有人担心……；concern＝担忧、关切。 |
| nutritional / intake | nutritional＝营养的；intake＝摄入量。 |
| mild winters | 温和的冬季；mild＝温和的。 |
| Even though | 尽管……（让步）；now that＝既然／由于（原因）。 |
| affordable childcare | 负担得起的儿童托育；affordable＝负担得起的。 |
| brick houses | 砖房；rows of tall brick houses＝一排排高高的砖房。 |
| per capita | 人均；per capita income＝人均收入。 |
