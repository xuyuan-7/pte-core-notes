# 2026-11-01｜生词与固定搭配

## 生词

| 英文 | 中文／用法 |
| --- | --- |
| ⭐ mean /miːn/ | v. 意味着；表示。例：This means students can learn at home. |
| ⭐ meaning /ˈmiːnɪŋ/ | n. 意思、含义；也可作 mean 的现在分词，表示“意味着”。例：The course is free, meaning everyone can attend. |
| indicate /ˈɪndɪkeɪt/ | v. 表明；显示；暗示。例：The results indicate an improvement. |
| ⭐ security /sɪˈkjʊərəti/ | n. 安全；安全感；保障；安保。例：Being part of a union gives workers a sense of security. |
| safety /ˈseɪfti/ | n. 安全；免受危险或伤害。例：The regulations improve workplace safety. |

## 固定搭配

| 英文 | 中文／用法 |
| --- | --- |
| ⭐ ..., meaning (that) ... | ……，这意味着……；用现在分词短语说明前述情况的含义或结果。例：The course is online, meaning students can study at home. |
| personalized feedback and support | 个性化反馈与支持。 |
| ⭐ a sense of security | 安全感。例：Workers feel a sense of security in the workplace. |
| ⭐ job security | 工作保障；工作稳定性。例：Employees worry about job security. |
| financial security | 经济保障。例：A stable income provides financial security. |
| workplace safety | 工作场所安全。例：Training improves workplace safety. |

## ⭐ 易错辨析

| 英文 | 中文／用法 |
| --- | --- |
| ⭐ meaning / indicating | meaning 强调“这意味着”并解释前述情况；indicating 强调“这表明”，侧重迹象或证据。二者部分语境可互换，不是绝对语法互斥。 |
| ⭐ security / safety | security 强调保障、免受威胁、稳定性（job security）；safety 强调免受事故、危险、伤害（workplace safety）。二者在一些语境中有重叠。 |

> 🔴 FIB-R #77 Oakham Career Programme（3/4）：误选 indicating，平台答案 meaning。真实错因不是简单近义词犹豫，而是之前只知道 meaning 的名词义“意思”，不知道其现在分词可表示“意味着”。后续重点检验是否能在新句子中独立理解 meaning。

> 🟢 FIB-R #80 The Role of a Union（4/4）：四空 members / solve problems / conditions / security 均正确。重点理解 security 在工会语境中的“安全感、保障”，并区分 job security 与 workplace safety。
