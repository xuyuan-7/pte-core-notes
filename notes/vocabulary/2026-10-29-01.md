### 10月29日追加｜observed（熟词僻义）

| 英文 | 中文／用法 |
| --- | --- |
| ⭐ observe / observed /əbˈzɜːrv/ | v. 观察；**遵守、庆祝／纪念（节日、纪念日）**。observed 是过去分词。本题原先不知道“纪念／庆祝”义，属于熟词僻义。例：United Nations Day has been observed on October 24 since 1948. |

| 固定搭配 | 中文／用法 |
| --- | --- |
| ⭐ observe a holiday / anniversary | 庆祝节日／纪念周年日；例：People observe the holiday every year. |
| be observed on + 日期 | （节日或纪念日）在某日举行纪念活动。例：United Nations Day is observed on October 24. |

> 易错辨析：observe 在科研语境常表示“观察”，在 holiday / anniversary / day 等语境则表示“庆祝、纪念、遵守”。本题用户虽然选对 observed，但不知道该词还有“纪念”含义，标记为需复习。

## 10月29日追加｜FIB-RW #28 Sales and Customers（2/5，重做仍错）

> 已做过的题仍错3空：writes → addresses；aggressive → demanding；it → there。用户明确反映“这道做过的还是错了”，优先作为二轮标红复习题。其余 which、fits 正确。真实原因待进一步核实，不简单归因为不认真。

### 生词（新增）

| 英文 | 中文／用法 |
| --- | --- |
| ⭐ address | v. 处理；探讨、讨论（问题）；n. 地址。本题误选 writes。例：The book addresses how sales can help organizations. |
| ⭐ demanding | adj. 要求高的；难以满足的。例：Businesses must respond to demanding customers. |
| aggressive | adj. 咄咄逼人的；激进的。例：The company uses aggressive marketing. |
| escalate / escalating | v.（使）升级、加剧；adj. 不断上涨的。例：Companies face escalating costs. |
| strategically | adv. 有策略地；战略性地。例：We allocate resources strategically. |
| allocate | v. 分配（资源、资金等）。例：Managers allocate resources carefully. |

### 固定搭配（新增）

| 英文 | 中文／用法 |
| --- | --- |
| ⭐ address an issue / question | 探讨或处理问题；例：The book addresses important questions. |
| ⭐ demanding customers | 要求很高的客户。 |
| customer-oriented | 以客户为中心的。 |
| increasing competition | 日益激烈的竞争。 |
| escalating costs | 不断上涨的成本。 |
| allocate resources strategically | 战略性地分配资源。 |
| fit into sth. | 适合／融入某种体系；例：fit into the business model. |

### ⭐ 易错辨析

| 英文 | 中文／用法 |
| --- | --- |
| ⭐ address / write | The book addresses how...＝本书探讨……；一般说 the author writes about，而非 the book writes。 |
| ⭐ demanding / aggressive | demanding customers＝要求高的客户；aggressive customers＝态度咄咄逼人的客户。后者语法可行，但本题商业环境语境优先 demanding。 |
| ⭐ there is uncertainty / it is uncertain | there is + 名词 uncertainty＝存在不确定性；it is + 形容词 uncertain＝情况不确定。题目误选 it，正确 there。 |

> 原题关键部分：The book addresses how sales can help organizations to become more customer-oriented... more demanding customers... within the industry there is still uncertainty... and how it fits into their organization's business model. 复习要点：同题反复错，需做变式迁移练习。
