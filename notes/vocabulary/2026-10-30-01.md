### 10月30日补充｜⭐ empower / grant 易错辨析

| 英文 | 中文／用法 |
| --- | --- |
| ⭐ empower sb. to do sth. | 赋予某人权力或能力去做某事；强调让人能够自主行动。例：The company empowers employees to make decisions. |
| ⭐ grant sb. sth. | 正式给予某人具体的许可、权利或资源。例：The manager granted me permission to leave early. |
| ⭐ grant permission / access / a request / a loan | 给予许可／访问权限；批准请求；发放贷款。 |
| empower employees / women | 赋能员工／赋予女性更多自主权。 |

> 用户主动指出 empower 和 grant 都像“给予”，易混淆。关键区别：empower 强调赋予人能力或自主权，grant 强调正式批准或给予某项具体权益、许可或资源。原题 granting customer financial demand 搭配不自然，不作为正确搭配背诵。

### ⭐ 易错辨析

| 英文 | 中文／用法 |
| --- | --- |
| ⭐ reduce / decrease | 许多语境下可以互换：reduce / decrease the number of cars 都成立；不要把题库答案当作唯一英语规则。 |

本题4空对2空：travel、public 正确；reduce 与 decrease 互换了位置。平台第二空标 decrease、第三空标 reduce。此处属于近义词辨析，但选词并非绝对唯一。

## 10月30日追加｜FIB-R Safety Clothing（安全服装与工作场所危险）

> 截图可见6个空：ensure、cause、minimize 正确；protect、supply、increase 放错位置。平台给出的正确答案依次为 ensure、prevent、protect、cause、supply、minimize。按截图判断本题为3/6。

### 生词

| 英文 | 中文／用法 |
| --- | --- |
| ⭐ ensure | 确保；保证。 |
| ⭐ prevent | 防止；预防。 |
| ⭐ protect | 保护；使免受伤害。 |
| gear | 装备；用具。 |
| cause | 导致；造成。 |
| slip | 滑倒；滑动；失误。 |
| ⭐ supply | 提供；供应。 |
| clothing | 衣物；服装（通常作不可数名词）。 |
| minimize | 使最小化；尽量减少。 |
| hazard | 危险；危害。 |

### 固定搭配

| 英文 | 中文／用法 |
| --- | --- |
| ⭐ prevent sb. from doing sth. | 防止某人做某事／防止某事发生。 |
| ⭐ protect sb. from sth. | 保护某人免受某种伤害。 |
| protective gear | 防护装备。 |
| supply clothing | 提供服装。 |
| supply sb. with sth. | 为某人提供某物。 |
| cause a slip | 导致滑倒。 |
| minimize hazards | 尽量减少危险。 |
| ensure that... | 确保……。 |

### ⭐ 易错辨析

| 英文 | 中文／用法 |
| --- | --- |
| ⭐ prevent / protect | prevent 强调防止某事发生；protect 强调保护人或物免受伤害。常见结构：prevent sb. from doing；protect sb. from sth. |
| ⭐ supply / provide | 都可表示“提供”；supply 常用于 supply sth. / supply sb. with sth. |
| ensure / insure | ensure＝确保；insure 通常指投保、为……上保险。 |

> 本题主要错因：将 prevent、protect、supply、increase 等选项位置混淆。复习时优先记住动词搭配和句子逻辑；不要只按中文近义词替换。

## 10月30日追加｜FIB-RW #36 Plants and Human Challenges（3/3）

> 第二轮三个空 shape、degradation、source 全对。用户特别说明 degradation 是记得上一轮的答案才选出来的，不能直接算作独立掌握。随后在新句子 Rapid industrial growth has contributed to serious environmental degradation in many regions. 中独立选对 degradation，说明有初步迁移能力，但仍需复习。
