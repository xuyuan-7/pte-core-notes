## FIB-RW #10 Children and Music｜6/6｜橙色：做对但不确定

- 六空均正确：surrounded / array / limitless / passive / conducted / is intruding。
- 重点不确定：第4空 passive（unchosen 与 not actively engaged 提示被动接受）；第5空 conducted（studies are being conducted＝现在进行时被动）；第6空 is intruding（intrude on＝干扰，it 指预录音乐）。
- 题目要点：孩子被各种音乐包围，但多数只是被动接受音乐；研究正在调查预录音乐是否干扰孩子自己创作音乐及相互交流的意愿。

## 固定搭配

| 英文 | 中文与记忆提示 |
| --- | --- |
| passive recipients | 被动接受者；与 active participation 对比 |
| conduct research / conduct a study | 进行研究；studies are being conducted＝研究正在开展 |
| intrude on / upon sth. | 干扰、侵扰某事；intrude on their desire to… |
| be surrounded by | 被……包围 |
| a wide array of | 各种各样的；近义 a wide range of |
| be inundated with | 被大量……充斥 |
| engage in | 参与、从事 |

## 易错点

- “are being + 过去分词”是现在进行时被动语态。
- “it is intruding on…” 中 it 指前面的 pre-recorded music；on 是 intrude 的搭配介词。
- 第4–6空虽然正确，但属于不稳固知识，复习时按橙色题处理。

## FIB-R #85 Popularizing Computers｜2/3｜红色：词性错误

- 正确：Popularizing、traced；第3空误选 created，正确答案 development。
- 原句：Popularizing computers began with the rise of the personal computer, a process that can be traced back to the early work in 1941, when the development of programmable machines started to influence modern computing.
- 核心错误：the created of programmable machines 不符合结构；the development of programmable machines 才能作为 started 的主语。
- 语法：the + 名词 + of + 名词；development 是名词，created 是动词过去式/过去分词。
- 复习标记：红色（做错），复习时先判断空格词性，再看上下文。

### 固定搭配（本题新增）

| 英文 | 中文与例句 |
| --- | --- |
| the development of | ……的发展；The development of technology takes time. |
| be traced back to | 可追溯到……；The tradition can be traced back to ancient times. |
| start to influence | 开始影响……；New technology started to influence education. |

### 生词（本题新增）

| 英文 | 中文、音标、英文例句 |
| --- | --- |
| development | /dɪˈveləpmənt/ 发展、开发（名词）。The development of computers changed society. |
| created | /kriˈeɪtɪd/ 创造了；被创造的（create 的过去式/过去分词）。The machine was created by engineers. |
| programmable | /ˈproʊɡræməbəl/ 可编程的。Programmable machines can follow instructions. |
| popularize | /ˈpɑːpjələraɪz/ 普及、推广。Schools helped popularize computers. |

### 易混淆

- development (n.)＝发展；develop (v.)＝发展、开发；created 是 create 的过去式或过去分词，不等于名词 creation。
- Popularizing computers 是动名词短语，在主句作主语；can be traced back to 是被动搭配。
