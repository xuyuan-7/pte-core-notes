## 🎤 口语 Speaking

### RA｜Read Aloud（无需固定文字模板）

**步骤**：看标点分意群 → 稳定语速朗读 → 生词不要反复卡住。练习重点为准确发音和自然流利度。

### RS｜Repeat Sentence（无需固定文字模板）

**步骤**：抓主干与信息词 → 听完立刻连贯复述 → 不要为回忆一个词长时间停顿。练习时逐渐做到音频只听一次。

### ⭐ RTS｜极简通用模板（2026-10-20 新增：替换两个关键词）

<details>
<summary>展开背诵｜固定开头＋事情＋请求／回应＋固定结尾</summary>

**① 固定开头**

Hello, how are you doing today? I hope you are doing well. I have something important that I'd like to discuss with you.

**② 事情（替换关键词）**

I'm contacting you about \[事情\].

**③ 请求（替换关键词）**

I was wondering if you could \[具体请求\].

**④ 固定结尾**

I really hope we can work out a good solution together. Thank you very much for your time and understanding.

**例子 A｜申请延期**：my assignment → give me more time to finish it.

**例子 B｜请求同事帮助**：our project → help me finish the project.

**例子 C｜酒店噪音投诉**：the noise in my room → help me solve this problem.

**重要提醒**：第③句只适用于请求类；道歉、解释、建议等情境，应改成对应的固定句（例如 I'm really sorry about \[事情\]. / I suggest that we \[建议\].），不能全部硬套请求句。优先准确回应题目；通用套话不保证 CLB9。

</details>

## 🆕 DI｜2026-11-05 三套分类模板＋备用模板（待试用）

> 这是新增的候选模板，供晚些时候比较、试练；暂不替换上方已选定的 graph 数据模板、流程图最终背诵版及图片模板。目标：保留熟悉句式，增加真实信息，减少空泛重复。

### 类型速查

| 图片类型 | 建议用语 | 模板 |
| --- | --- | --- |
| 柱状图、折线图、饼图、表格 | chart（折线图也可 graph；表格可直接 table） | ① 数据 |
| 流程图、循环图 | diagram / process | ② 流程 |
| 地图、照片、结构示意图 | picture / map / diagram | ③ 图片 |
| 难以分类的复杂图 | picture | ④ 备用 |

### ① 数据图表｜候选简化版

The following chart shows information about \[title\].

As we can see, there are different categories, such as \[A\], \[B\] and \[C\].

The highest value is \[number\], while the lowest value is \[number\].

In addition, \[one accurate comparison or trend\].

Overall, the chart provides useful information about \[title\].

**替换重点**：标题、类别、最大/最小值、一个趋势或比较。没有最大/最小值就改说真实数据；表格可把 chart 换成 table。原 graph 模板仍保留。

#### 折线图趋势句｜2026-11-05新增（可直接背诵）

| 趋势 | 英文句子 |
| --- | --- |
| 两条线都上升 | Both elements show an upward trend over time. |
| 两条线都下降 | Both elements show a downward trend over time. |
| 一升一降 | One element increases, while the other decreases. |
| 基本稳定 | Both elements remain relatively stable over time. |

**统一用词**：数据图开头可统一用 chart，介绍内容可用 elements（不必强制换成 categories）。折线图描述顺序：标题 → elements → 最大值/最小值 → 趋势 → 结尾。只选符合图中真实走势的句子。

**示例｜Mobile phone ownership**：Both elements show an upward trend over time.（手机与智能手机拥有率整体上升。）

### ② 流程图｜候选简化版

The following diagram shows the process of \[title\].

As we can see, there are several important stages in this process.

First, \[step 1\].

Next, \[step 2\].

Then, \[step 3\].

Finally, \[final step or result\].

Overall, the diagram shows how \[process\] works.

**提醒**：按箭头和真实步骤描述。此前「The first step is to...」版本仍为已选定背诵版，此处只是备选。

### ③ 地图、照片、结构图｜候选简化版

The following picture shows \[topic\].

As we can see, there are several important elements in this picture.

On the left, we can see \[A\].

On the right, there is \[B\].

In the center, we can see \[C\].

Overall, the picture shows \[main point\].

**提醒**：位置句仅在图片确有对应位置时使用；否则改为 At the top / In the background 或直接描述主要对象。

### ④ 复杂图片｜备用框架

The following picture shows information about \[title\].

As we can see, the main topic is \[topic\].

There are several important elements, including \[A\], \[B\] and \[C\].

One important feature is \[accurate detail\].

Another interesting point is \[accurate detail\].

Overall, the picture provides information about \[topic\].

**提醒**：备用框架不能替代真实内容；尽量说出至少2–3个准确细节，不要为了凑时间重复无信息句。

### 训练建议（待调整）

- 每日DI约15–20分钟：数据图2张、流程图1张、其他图1张；备用模板不必每天练。
- 目标在40秒答题时限内连贯输出，优先内容准确、发音清楚、减少停顿。
- 不必每种图背一套；优先比较上述三类是否比原模板更顺口，试练后再决定正式替换。
